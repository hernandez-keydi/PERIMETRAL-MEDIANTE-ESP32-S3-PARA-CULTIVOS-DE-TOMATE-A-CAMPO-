# PERIMETRAL-MEDIANTE-ESP32-S3-PARA-CULTIVOS-DE-TOMATE-A-CAMPO-
El presente proyecto detalla la conceptualización e implementación de un nodo de sensado  inteligente basado en la arquitectura del microcontrolador ESP32-S3 WROOM, diseñado  específicamente para la tecnificación y optimización de cultivos de tomate a campo abierto en la  provincia de Coclé.
